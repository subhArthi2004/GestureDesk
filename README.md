# 🖐️ GestureDesk

> A real-time, touchless desktop presentation controller powered by Computer Vision and OpenCV. GestureDesk enables users to control PowerPoint and PDF presentations, annotate slides, zoom, and navigate seamlessly using hand gestures captured by a standard webcam.

---

## ✨ Features

* **🤚 Open Palm:** Start Presentation (`F5`)
* **✊ Closed Fist:** End Presentation (`ESC`)
* **👍 Thumbs Up:** Toggle Black/Blank Screen (`B`)
* **✌️ Peace Sign:** Toggle Digital Pen/Laser Tool (`Ctrl` + `P`)
* **🤟 Three Fingers:** Jump directly to the First Slide (`Home`)
* **👆 Index Finger Point:** Horizontal Swipe Tracking (Next / Previous Slide)
* **🤏 Pinch Gesture:** Dynamic Distance Sensing (Continuous Zoom In / Zoom Out)
* **💻 Custom OpenCV HUD:** Real-time visual interface displaying live FPS, current gesture state, hold progress bars, pinch meters, and action logs.

---

## 🚀 Quick Start (No Python Required)

1. Navigate to the **[Releases](https://github.com/subhArthi2004/GestureDesk/releases)** section on the right side of this repository.
2. Download **`GestureDesk.exe`**.
3. Double-click to launch! *(Works on Windows without installing Python or external dependencies).*
